# 奶蛙 on Desk 1.3.3

「惊鸿一瞥」待机调整为更从容的 6 秒循环：

**正放 1 秒 → 看向你停留 2 秒 → 倒放回位 1 秒 → 正常站姿休息 2 秒。**

- 明确保留轻瞥后的 2 秒停留，回到正常站姿后再开始下一轮。
- 继续复用原片已经抠好的透明帧，47 帧无损编码；末帧和首帧为相同的正常站姿，无淡化回接。
- 逐帧核对可见像素、透明度与停留时长，身体比例和抠图保持不变。
- 其余动作、12 秒大笑及全部音效与 1.3.2 完全一致，没有调用生成 API。

## 安装与更新

Apple Silicon Mac 下载 `Naifrog-on-Desk-1.3.3-arm64.dmg`，退出正在运行的桌宠，将 **Naifrog on Desk.app** 拖入 Applications，替换旧的奶蛙版应用。也提供 ZIP、独立主题包 `Naifrog-1.3.3.zip`、SHA256SUMS.txt 和验证报告。

新安装默认奶蛙，已有主题选择保留。使用内置奶蛙时更新应用即可；使用原版 Clawd 时，可导入独立主题包。

本版为 **ad-hoc 签名，未做 Apple 公证**，首次打开可能需要 macOS「隐私与安全性」确认。自动升级安装及其他平台尚未验收，请从 Releases 手动更新。原版和奶蛙版共享 agent hooks 与 `~/.clawd`，请只运行其中一个。

验证范围及未验证项见 `verification.json`。保留 AGPL-3.0-only 与上游作者、贡献者归属说明。
