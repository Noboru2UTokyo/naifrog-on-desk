# 奶蛙 on Desk 1.4.1 · 署名与发行整理

由 **[Noboru2UTokyo](https://github.com/Noboru2UTokyo) 发起、主导设计并维护**的奶蛙社区发行版，基于 rullerzhou-afk 及贡献者开发的 Clawd on Desk v1.3.0。

## 本版更新

- 在应用「关于」页显著展示奶蛙版发起人、设计主导与维护者，说明素材选用、角色统一、动画设计与打磨、状态映射、界面配色、验收和发行维护的贡献。
- 将奶蛙版仓库、原版作者、上游仓库与上游维护者分别列出，保留完整原项目归属。
- 统一七种界面语言的应用名称与贡献说明，「关于」页使用奶蛙形象；主题作者和分发元数据同步更新。
- 整理 GitHub 首页、安装分享步骤、动作触发表和版本验证记录。
- 沿用 v1.4.0 已验收的全部动画、图片和声音：6 秒惊鸿一瞥、12 秒大笑、托腮、打字／耳机／施工、吹泡泡与连续趴睡／醒来。

奶蛙原角色与原始素材的权利归各自权利人所有。奶蛙版署名对应主题适配、创意指导及发行维护；代码和适配素材制作使用了 AI 辅助。详见 [NOTICE.md](https://github.com/Noboru2UTokyo/naifrog-on-desk/blob/v1.4.1/NOTICE.md)。

## 安装与更新

Apple Silicon Mac 下载 **Naifrog-on-Desk-1.4.1-arm64.dmg**，退出正在运行的桌宠，将 **Naifrog on Desk.app** 拖入 Applications 后启动。升级保留现有设置，新安装默认奶蛙。分享本 Release 链接即可，使用动画和声音不需要生成服务或 API Key。

也提供应用 ZIP、独立主题 **Naifrog-1.4.1.zip**、**SHA256SUMS.txt** 和 **verification.json**。

本版为 **ad-hoc 签名，未做 Apple 公证**。跨版本自动更新安装和其他平台尚未验收，请从 Releases 手动更新。原版与奶蛙版共享 agent hooks 和 `~/.clawd`，请只运行其中一个。

验证范围与未验证项见随包提供的 verification.json。保留 AGPL-3.0-only 许可证及上游作者、贡献者归属。
