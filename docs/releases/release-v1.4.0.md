# 奶蛙 on Desk 1.4.0

内置已经本地验收的新动作：工作按会话数量持续循环，不再定时轮换六种办公动作。

- 1 个工作会话打字，2 个戴耳机，3 个及以上施工；子代理统一使用选定的上一版耳机。
- 思考重做为原图托腮，保留手掌包住下巴、弯曲手指、横抱手臂和头部倾斜。
- 睡眠采用连续趴下、趴卧呼吸、撑起醒来；空闲时增加吹泡泡。
- 取消三球接抛和爬行。新安装默认关闭自由漫游；奶蛙主题的漫游视觉回退为原待机。
- 原版 6 秒「惊鸿一瞥」、12 秒大笑及 Permission／大笑音效保持原文件不变。
- 设置、会话面板和提示气泡采用奶黄色与绿色点缀，保留警告、错误及 Agent 身份色。
- 已验收素材直接打包，不在发布阶段重新生成；工作切换为 140ms 淡接。

## 安装与更新

Apple Silicon Mac 下载 `Naifrog-on-Desk-1.4.0-arm64.dmg`，退出正在运行的桌宠，将 **Naifrog on Desk.app** 拖入 Applications。也提供 ZIP、独立主题包 `Naifrog-1.4.0.zip`、SHA256SUMS.txt 和验证报告。

新安装默认奶蛙，已有主题选择保留。原版 Clawd 用户可导入独立主题包。已有用户如启用了自由漫游，可在设置中关闭；本轮本机安装已关闭它。

本版为 **ad-hoc 签名，未做 Apple 公证**。自动更新安装及其他平台尚未验收，请从 Releases 手动更新。原版与奶蛙版共享 agent hooks 和 `~/.clawd`，请只运行其中一个。

验证范围及未验证项见 `verification.json`。保留 AGPL-3.0-only 与上游作者、贡献者归属说明。
