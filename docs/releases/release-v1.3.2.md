# 奶蛙 on Desk 1.3.2

「惊鸿一瞥」待机现在会正放后倒放，自然回到起始姿势，2 秒完成一个往返循环。

- 直接复用 1.3.1 已抠好的 24 个原片动作帧，排成 46 帧。
- 去掉原来的长停顿与淡化回接，转折处不重复首尾帧。
- 使用无损 WebP；逐帧验证透明度与可见像素完全保留，身体比例、颜色和抠图边缘不变。
- 其余工作、思考、爬行、睡眠、12 秒大笑与音效保持原样；没有调用视频生成 API。

## 安装与更新

Apple Silicon Mac 下载 `Naifrog-on-Desk-1.3.2-arm64.dmg`，退出正在运行的桌宠，将 **Naifrog on Desk.app** 拖入 Applications，替换旧的奶蛙版应用即可。也提供 ZIP、主题单独导入包和 SHA256SUMS.txt。

新安装默认奶蛙，已有设置保留。此前选择的是内置奶蛙主题时，更新应用即可使用新循环；原版 Clawd 用户可单独导入 `Naifrog-1.3.2.zip`。

本版仅使用 **ad-hoc 签名，未做 Apple 公证**，首次打开可能需要 macOS「隐私与安全性」确认。自动升级安装、其他平台和架构尚未验收，请使用 Releases 手动更新。原版与奶蛙版沿用相同的 agent hooks 和 `~/.clawd`，请只运行其中一个。

验证详情见随包的 `verification.json`。代码公开于本 fork，保留 AGPL-3.0-only、原作者与所有上游贡献者的归属说明。
