奶蛙 · 大笑伙伴 1.3.1
适用：Clawd on Desk 1.2.0，标准桌宠模式。

本次更新：待机改为用户指定的 ScreenRecording_10-15-2026 21.mov「惊鸿一瞥」。保留原片约 1 秒的正向动作，加停顿及 320 ms 回接，4 秒循环；只去背景和等比例适配，没有新生成。

上一版本：取消“诡异”风格，补充翻资料、记笔记、盖章三种自然办公动作，所有动作按原设定图保持造型，保留长而收细的黄色腿、细脚踝、黄色脚面与深色趾尖、梨形大腹部和原头身比例。旧版短腿、大脚生成素材已停止使用。
已有补充视频使用完整 MiniMax H3 的 2K 档，原始视频短边为 1440、24 fps（竖版 1440×2560，打字及三种新增动作方版 1440×1440）；运行用透明 WebP 为 640×640。
只做动作和道具的有限适配。爬行、大笑、睡眠继续使用同一源片、帧段和时长，重新优化透明边缘；音频逐字节保持不变。

安装：Clawd 设置 → Theme → Import Clawd theme package (.zip)，选择 Naifrog-1.3.1.zip；选择「奶蛙 · 大笑伙伴」。
也可将 naifrog 文件夹放到 macOS ~/Library/Application Support/clawd-on-desk/themes/，刷新主题后选择。
恢复：选择之前的主题；安装脚本先备份已有同名主题。

动作：
- 待机：用户原片站姿眨眼、转头轻瞥，4 秒一轮。
- 漫游：沿用原片趴地爬行，实际位移由 Clawd 控制。
- 思考：托腮、另一臂横向抱住，只做微小眼神和眨眼动作；身体以完整原设定图为基准。
- 工作：打字 → 翻资料 → 记笔记 → 打电话 → 汇报 → 盖章，六种动作按 32 秒周期自动轮换。单段素材也可在设置中替换使用。
- 大笑：原始连续 10.8 秒段放慢为 12 秒；完成音效、完成事件和点击大笑反应同步为 12 秒。
- 电话：只保留生成片段中干净的白底尾段，剔除模型擅自加入的转场。
- 入睡／醒来：原有连续趴姿动作，醒来为同段倒放，结束后淡化切回站姿待机。

触发与声音：
- 思考、工作、完成、等确认和错误由 Clawd 会话事件触发。
- 并发工作、搬运和清理复用工作轮换；等待确认和错误复用思考。
- 当 Clawd 提供原版阅读／调试动作提示时，分别显示翻资料／记笔记；并非每个工具事件都携带这类提示，没有提示时按正常工作轮换。
- 空闲且未开启免打扰时，快速两次点身体左侧大笑、右侧思考；快速四次点击大笑。单击主要显示操作条。
- 普通点击反应不播放完成事件声音；complete.mp3 / confirm.mp3 绑定完成与 Permission 确认事件，复用 1.2 的原音频。
- 所有声音仍由原始大笑剪辑、变速、变调；无合成对白或背景音乐。
- 鼠标静止约 60 秒开始犯困、约 90 秒伏睡，忙碌会话可能抑制睡眠。

画面：全程仅统一缩放与平移，不做非等比拉伸或逐帧变形。工作内部短淡化换道具，普通状态 180 ms 淡化。
抠图：按边缘颜色估计透明度、去白底残色、保留细手指脚趾与道具，再以预乘透明度缩放，减少黑边和白边。
内容：16 个透明动作文件、对应省电静帧、15 个状态映射、5 个大笑变体。
限制：无独立迷你模式、实时眼球追踪；省电静帧模式会停用动画。实际漫游路线由 Clawd 控制。
上游的 Static Theme 标记只表示单一待机槽，idle.webp 本身为动画。

原设定与生成规则记录于项目 reference/character-policy.json 和 AGENTS.md；验收页提供等高原设定对照。
运行主题不需要 API Key 或网络，凭据不在主题包内。
