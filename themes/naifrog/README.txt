奶蛙 · 大笑伙伴 1.4.1

奶蛙版发起、设计主导与维护：Noboru2UTokyo
负责原素材选用、形象统一、动画设计与打磨、状态映射、界面配色、验收和发行维护。
基于 rullerzhou-afk 及贡献者开发的 Clawd on Desk；奶蛙原角色与原素材归各自权利人所有。
https://github.com/Noboru2UTokyo/naifrog-on-desk

本地验收通过的奶蛙动作包。视频补充使用完整 MiniMax H3、1440×1440、24fps；运行素材为透明 640×640 WebP。原设定只提供造型、比例、颜色和材质，各动作独立设计姿势。

待机：原片惊鸿一瞥，正放 1 秒 → 停留 2 秒 → 倒放 1 秒 → 正常站姿停留 2 秒，共 6 秒。
思考：按用户原图托腮，6.417 秒循环。
工作：1 会话打字、2 会话戴耳机、3+ 会话施工；所有子代理统一耳机。每段持续循环到状态变化，不再定时轮换。
辅助：阅读和记笔记仍用于上游对应显示提示；空闲可吹泡泡 8 秒。
睡眠：8 秒连续趴下 → 趴卧呼吸循环 → 8 秒撑起醒来。dozing/collapsing/sleeping 使用同一个趴睡循环，避免重复趴下。
取消三球接抛和爬行。漫游视觉回退 idle；请在应用设置中关闭自由漫游。
大笑：原 12 秒动画。原大笑和 Permission 音效字节不变。

状态间 140ms 短淡接；入睡、趴睡和醒来保留已对齐的实际动作。只等比缩放与固定平移，不变形身体。
安装：设置 → Theme → 导入 Naifrog-1.4.1.zip。奶蛙发行版已内置，无需单独导入。
无独立迷你模式或实时眼球追踪。运行不需要 API Key 或生成服务。
批准素材、时长及 SHA-256 记录在 approved-assets.json；原设定与素材归属保留。
